# ♻️ Waste Track

Waste Track is a full-stack web-based waste management and monitoring system designed to streamline waste collection, reporting, and data management processes. The platform provides dedicated functionalities for both users and administrators, enabling efficient waste tracking, centralized analytics, user management, and reporting across the entire system.

The system allows users to submit waste reports and collection requests, monitor their activities through a waste timeline, and manage their own records. Administrators can oversee all system activities through a centralized dashboard, manage users, analyze waste-related data, export records to Excel files, and maintain accountability through record management tools.

---

## 📌 Overview

Waste Track aims to improve waste management processes by providing a centralized platform for waste reporting, collection tracking, analytics, and user management.

The platform promotes better waste monitoring and accountability through:

# 📊 System Workflow

1. Users create an account or sign in using email or Google Authentication.
2. Users submit Waste Reports or Waste Collection Requests.
3. Submitted records are stored in the system database.
4. Records automatically appear in the user's Waste Timeline.
5. Users can update or delete their submitted records.
6. Administrators manage reports, collections, and users through dedicated management modules.
7. Analytics automatically aggregate system-wide data.
8. Records can be searched, filtered, monitored, and exported to Excel files.
9. Deleted records are tracked for accountability and auditing purposes.
